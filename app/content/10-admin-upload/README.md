# 10 — Admin upload files

Every placement test, practice exercise and full exam paper, converted to the JSON
shape that the B2 admin upload (`/b2admin`) accepts. The field names and structure
match the b2-samples upload guide exactly, so each file can be uploaded as it is.

Generated by `app/server/tools/export_admin_upload.js` from `app/content/1-3`. Do not
edit these files by hand: change the content, re-run `export_content_tree.js`, then
re-run `export_admin_upload.js`.

## Folders

| Folder | Upload as | Shape |
|---|---|---|
| `exercises/<module>/<tag>/` | module exercise (Reading / Listening / Writing / Speaking page) | exercise JSON |
| `exam-papers/<goethe\|telc>/` | full exam paper | exam-paper JSON |
| `placement-tests/` | the 10 comparable 15-minute tests (core-2026b v1–v10) | exam-paper JSON |

- `tag`: `goethe`, `telc`, or `all` (Skillcase's own practice content).
- `module`: grammar and vocabulary drills are under `reading`, which is where the app shows them.
- **Placement tests** use `"exam_type": "skillcase"`. The uploader currently accepts only
  `telc|goethe`, so either allow `skillcase` or store these as a separate test list.
  They must stay out of the Full Exam Papers list.

## How our item types were converted

| Ours | Upload `type` | Note |
|---|---|---|
| MCQ | `mcq_single` | answer = letter |
| TRUE_FALSE | `true_false` | options `Richtig`/`Falsch` |
| MULTI_SELECT | `mcq_multi` | answer = letter array |
| MATCHING | `matching_headers` (`matching_ads` for Anzeigen) | one item per left-hand entry, in its own block |
| GAP_FILL | `fill_blanks` | one item per gap; other gaps shown as (1), (2)…; accepted spellings include both cases |
| ORDERING | `mcq_single` | one item per position: "Was steht an Stelle N?" |
| SHORT_TEXT / LONG_TEXT | writing item | `word_limit` = target length; Leitpunkte appended to `question` |
| SPOKEN_RESPONSE | speaking item | one item per block; `speech_time_limit` = speaking seconds |

For writing and speaking, `expected_answer` (and for speaking also `reference_text` /
`model_answer`) is the B2 model answer from `app/server/src/seed/b2/model_answers.json`.
**These are AI drafts that no one has reviewed yet.** A teacher should check them
before they are used for scoring.

## Audio

`audio` holds a filename, which the uploader resolves against the attached ZIP.
`_media-manifest.json` lists which files each upload needs. All source mp3s are in
`app/server/public/b2/audio/`. To build every ZIP (flat, one per JSON that has audio),
run this from `app/server`:

```bash
node tools/export_admin_upload.js --zips
```

The ZIPs are written to `app/content-upload-zips/`, which is gitignored.
Files without audio (reading, writing, speaking) are uploaded as the JSON alone.
